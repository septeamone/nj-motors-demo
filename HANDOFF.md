## 2. Как работать
- Собрать и посмотреть локально: `npm run build`, затем `node scripts/serve.mjs 8772 out` → http://localhost:8772/ .
- **Важно:** `publish-preview.sh` и `publish-pages.sh` пересобирают `out/` с другим адресом (`/nj-motors-demo/...`). После них локальная страница белая — снова `npm run build`.
- Проверять всё в headless Playwright (без окон у Jack, звук глушить `--mute-audio`, `--enable-gpu --ignore-gpu-blocklist`). Playwright стоит в scratchpad сессии (`npm i playwright` там). В тестах: `localStorage cookie-ok=1`, заставка ждёт нажатия на `.intro-hint`.
- Размеры телефонов для проверки: 320×568, 360×640, 360×780, 375×667, 390×844, 412×915, 430×932, 768×1024. Плюс ПК 1024/1440/2000. Обе темы (`localStorage site-theme=light|dark`).
- Проверять: боковой прокрутки нет нигде (страница и меню), первый экран телефона вмещает 4 плашки с пояснениями, текст поверх роликов читается в обеих темах, плавность (телефон с CPU ×4 ≈ 60 к/с).
- Длинные правки текста: через python-скрипт в scratchpad (`python -I file.py`), а не через heredoc в bash: Git Bash ломается на русском тексте с кавычками.
- `npx eslint <файлы>` и `npm run build` перед коммитом. Коммиты с подписью `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## 7. Стиль и грабли
- Краски: чернильный #040c14, крафт (`--paper`), красный #d40404 (действия, печати). Шрифты: Fira Sans Extra Condensed (заголовки), Russo One (цифры, кнопки), Onest (текст). Ритм движения `lib/motion.ts`.
- Без нейрослопа: нет мелких заглавных надписей над заголовками, точечного фона, свечения кнопок; разделы разделяются тоном фона. Нумерация только у настоящих шагов (этапы, платежи).
- Переносы слов выключены на всём сайте (`p { hyphens: manual }`) — Jack против переносов.
- **CSS-слои:** почти всё в `globals.css` лежит внутри `@layer components` (строки ~186–519). Правило внутри слоя **проигрывает** любому правилу вне слоя, даже с более точным селектором (так сломался цвет подзаголовка на стекле). Новые переопределения таких правил класть **в конец файла, вне слоя**.
- Текст поверх роликов — обёртка `data-theme="dark"` (как у каталога и стекла «Процесса»), иначе в светлой теме он тёмный на тёмном.
- Ролики: кадры в `public/films/<name>/{d,m}`, проигрыватель `FilmCanvas.tsx`. Новые ролики — Higgsfield, Kling 3.0 pro (не 4K, экономия кредитов).
- Видео отзывов: 720p ~2 Мбит/с + лёгкая копия `*-sd.mp4` (выбирается на медленной связи, `lib/net.ts`, `lib/video.ts`), обложка `*-poster.webp`.
